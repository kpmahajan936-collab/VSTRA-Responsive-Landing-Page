# VSTRA — Wear Your Vibe

A responsive fashion landing page for VSTRA, a fictional clothing brand featuring **Ethnic, Western and Fusion** styles.

## Features
- Responsive desktop and mobile layouts
- Navigation with mobile menu
- Hero section with call-to-action
- Ethnic, Western and Fusion collection cards
- Featured product cards with interactive favourite buttons
- Brand story and three feature cards
- Newsletter form interaction
- Footer with navigation and contact links

## Tech Stack
- HTML5
- CSS3 (Grid, Flexbox, media queries)
- Vanilla JavaScript

## Run locally
1. Download or clone this repository.
2. Open the folder in Visual Studio Code.
3. Open `index.html` with Live Server, or double-click it to open in a browser.

## Design direction
- Background: deep charcoal / near-black
- Accent: muted violet and lavender
- Typography: Space Grotesk, Playfair Display and DM Sans
- Audience: people who enjoy both Indian ethnic wear and contemporary western fashion.

## Note
This is a front-end demonstration. Product names, prices, email address and newsletter interaction are sample content. The newsletter form does not send data to a mailing service. Product photos load from Unsplash and therefore require an internet connection.
